# Bookmark App

Gestionnaire de favoris en HTML/CSS/JS vanilla, persistance via localStorage.
Pas de framework, pas de backend. Code commenté en français.

## Fichiers
- index.html : structure de la page
- style.css : mise en forme
- app.js : logique (ajout, affichage, recherche, suppression, édition)
